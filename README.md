## 🚀 Overview

I am a senior full-stack software developer and programming instructor with deep expertise in modern web development, backend systems, software architecture, and teaching technical concepts. I design end-to-end platforms from UI to data layers, with a focus on clarity, reliability, and learning at scale.

**What I do now**

- Lead full-stack builds with React, Next.js, Node.js, Express.js, and FastAPI (Python)
- Architect .NET and ASP.NET services with clean boundaries and scalable patterns
- Design secure APIs with auth, RBAC, and middleware-first pipelines
- Build data layers with PostgreSQL, MongoDB, MySQL, Oracle, and Redis
- Create AI features with LangChain and RAG pipelines for real products
- Teach frontend and backend engineering through long-form workshops
- Run Linux-first workflows and help teams migrate their dev environments

<details>
  <summary><b>How I work</b></summary>
  <br />
  <ul>
    <li>Systems first, UI second, data last</li>
    <li>Small interfaces, clear contracts, documented tradeoffs</li>
    <li>Teaching mindset: explain the why, not just the how</li>
  </ul>
</details>
